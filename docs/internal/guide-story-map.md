Implementation references for maintainers auditing the shadcn Base catalog. The refreshed official sources contain 437 ComponentPreview occurrences across 61 registry guides. Every occurrence below links to its upstream example source and corresponding local stories; 509 distinct story exports are referenced. The two HoverCard demo occurrences intentionally remain separate rows.

The [source refresh](../../.tmp/catalog-guide-current.log) checks all 63 registry names: Form and Sonner return 404 for Base MDX, and the other guides retain the cached preview sets. The [AST reference check](../../.tmp/catalog-guide-map-integrity.log) finds no missing local story exports. These checks establish source and reference integrity. Browser behavior, deliberate adaptations, negative controls and independent archive consumption are recorded in the [catalog audit](./catalog-audit.md), with the current catalog-wide results in its [completion gates](./catalog-audit.md#completion-gates).

Several guide compositions reuse another family's stories: checkbox tables use Table selection, choice cards use Field, and Persian Calendar uses the maintained Persian primitive. A preview may map to complementary stories when its API behaviors are covered separately. The index does not claim a pixel-for-pixel copy of upstream demo content or that one passing story proves every behavior in a linked example.

[just fix](../../.tmp/catalog-guide-map-fix.log) and [just check](../../.tmp/catalog-guide-map-check.log) pass, including ten package-render tests and the static Storybook build. Existing dependency-directive and chunk-size warnings remain. This indexing pass changes documentation and adds no component runtime behavior.

## Composition boundaries and adaptations

- Form has no component source in the current registry. [Field.FormComposition](../../src/components/stories/forms/Field.stories.tsx) and the [consolidated archive consumer](./catalog-audit.md#consolidated-public-package-audit) exercise React Hook Form/Zod validation, submission and controlled reset. This is not a claim that every advanced recipe of every form library is implemented.
- Sonner remains a separate public notification API. Its advertised Base documentation URL redirects to Toast; the [Sonner stories](../../src/components/stories/feedback/Sonner.stories.tsx) and the native archive-consumer action checks provide its evidence.
- Button navigation uses a native anchor styled by buttonVariants. Pagination likewise preserves native links. The upstream Button-as-link composition is adapted to the native primitive contract described in the audit.
- The Calendar guide's calendar-hijri preview explicitly imports the Persian calendar. PersianCalendar uses native Solar Hijri arithmetic and Gregorian Date callback values; no Islamic lunar calendar support is inferred from that preview name.
- Spinner's custom example replaces its implementation with another icon. The package's CustomLabel story exercises supported SVG props/ref/accessibility; it does not introduce an alternate-icon API.
- Native uncontrolled Checkbox, Switch and Select form reset limitations remain documented. Controlled onReset compositions supply matching rendered state and submitted values.
